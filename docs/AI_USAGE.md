# Использование генеративного ИИ

В ходе работы над проектом генеративный ИИ использовался в качестве вспомогательного инструмента для консультаций, уточнения формулировок, структурирования документации, ускорения написания кода и дополнения отдельных идей. Все предложенные материалы проверялись, дорабатывались и адаптировались участниками команды под архитектуру и реализацию проекта LoyaltyLedger.

# Contributions

В разработке LoyaltyLedger участвовали три человека. Работа была разделена на реализацию программной части и подготовку проектной документации.

## Волкова Татьяна

Основная зона ответственности: **разработка программной части проекта**.

Выполненные задачи:

- реализована основная backend-часть LoyaltyLedger на Go;
- реализована регистрация и аутентификация пользователей;
- добавлено безопасное хранение паролей;
- реализованы пользовательские сессии и bearer-токены;
- добавлена проверка ролей `user` и `admin`;
- реализованы пользовательские и административные API endpoint'ы;
- реализована работа с PostgreSQL;
- реализованы начисление и списание бонусных баллов;
- добавлена защита от повторного начисления бонусов;
- реализовано атомарное списание бонусов;
- реализованы фоновые обработчики заказов;
- реализовано взаимодействие с внешним Order Service;
- добавлена валидация входных данных и обработка ошибок внешнего сервиса;
- подготовлены Docker Compose, миграции и тесты проекта.

Основной результат работы: **запускаемая и функциональная версия LoyaltyLedger, реализующая основные пользовательские и административные сценарии проекта**.
